# 数电学习 HTML 演示

无需安装软件、无需联网：下载仓库中的 HTML 文件，在电脑或手机浏览器中打开即可使用。

## 卡诺图编辑器

**[打开源文件：Karnaugh Studio 交互式卡诺图](karnaugh-map.html)**

- 支持 2–6 变量，行列自动使用格雷码顺序。
- 点击格子设置 0 / 1 / X；支持手动输入最小项和无关项。
- 实时生成与或式（SOP）和或与式（POS），自动绘制圈组，支持跨边界相邻。
- 支持两角点手动画圈、覆盖提示、复制表达式、导出 SVG 图。
- 无第三方依赖，编辑内容保存在当前浏览器中。
