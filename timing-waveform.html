采样约定与使用说明

每一格代表一个时间区间，格内电平保持不变。默认在有效边沿读取前一格的数据；可改为读取本格。多个触发器在同一边沿同时更新，级联数据始终读取更新前的 Q。初态对应第 0 格，第 0 格之前不假定额外的时钟边沿。

D：采样 D；JK：00 保持、01 置 0、10 置 1、11 翻转；T：0 保持、1 翻转；RS 为高有效同步边沿触发器，R=S=1 时输出 X。这里不模拟异步 RS 锁存器、传播延迟、建立/保持时间或亚稳态。X 表示无法确定的逻辑值。悬空输入与可能发生的未知时钟边沿会保守传播 X。

点击信号名称打开设置。自动时钟和触发器输出由参数生成；直接画波形需切换为“手动信号”。支持旧 JSON 工程；工程自动保存在当前浏览器，也可导出 JSON 备份。
